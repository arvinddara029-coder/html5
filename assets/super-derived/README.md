# Derived guardian sprites

These PNGs are offline raster renders of the **eleven supplied FBX files**, using a lightweight material approximation and a selected base texture from each pack. `models.json` records the source FBX, referenced textures and original animation count.

Each sheet has four 256×256 angle views of the model's rest pose. The game uses them as **hovering statue-style guardian enemies**. They are not complete 3D/rag-doll/rig-animation conversions, and alternate outfit/material authoring content is not all reproduced.

Authors from the original pack README:

- DarksArtworks — Mr. Virtual v2, GB, John Dick
- Sharkman — OGN/IHY Luigi
- Thanks to Marco Antonio and the Mario's Madness team

Keep the original README and these credits with redistributed derivatives. Original sources are unmodified under `assets/super/Mario's Madness Model Pack v2`.

Rebuild with `scripts/render-model-browser.js` and `scripts/render-models.mjs`; follow `EVOLUTION.md` for build-only tooling.
